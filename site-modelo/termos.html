1. O que é

O AutoPost é uma ferramenta pessoal e auto-hospedada para agendar e publicar vídeos curtos nas contas do próprio usuário no TikTok, YouTube e Instagram, usando as APIs oficiais dessas redes.

2. Responsabilidade pelo conteúdo

Você é responsável pelos vídeos e textos que publicar, incluindo direitos autorais, músicas e imagens de terceiros. Antes de publicar, revise os textos sugeridos pela IA. Use o AutoPost só em contas que são suas ou que você tem autorização para gerenciar.

3. Regras das plataformas

Ao usar o AutoPost você também concorda com as regras de cada rede: Termos de Serviço do YouTube, Termos de Serviço do TikTok e Termos de Uso do Instagram. O AutoPost respeita os limites de publicação de cada API e não deve ser usado para spam nem para engajamento artificial.

4. Disponibilidade

O AutoPost roda no seu computador e depende dele estar ligado e conectado à internet nos horários agendados. As redes podem mudar ou limitar as APIs a qualquer momento. A ferramenta é fornecida "como está", sem garantia de que cada post será publicado.
